# Governance Model

## Required artifacts

- Architecture decision records
- Threat model
- Data inventory
- Retention policy
- Permission catalog
- Event catalog
- Dependency inventory
- Release notes
- Security review evidence

## Definition of Done

A feature is complete only when applicable items are addressed:

- Domain rules and boundaries are explicit
- Authorization is implemented and tested
- Tenant isolation is verified
- Security and privacy impact are reviewed
- Audit events are defined
- i18n keys are complete
- Accessibility is reviewed
- Logs exclude sensitive data
- Tests cover success, failure and abuse paths
- Documentation is updated

## Change governance

Breaking architectural changes require an ADR. Security-sensitive changes require explicit review notes and rollback guidance.

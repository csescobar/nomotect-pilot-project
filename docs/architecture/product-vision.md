# Product Vision

## Purpose

Rails Hotwire Platform is an open-source, modular foundation for building secure and maintainable enterprise applications with Ruby on Rails and Hotwire.

The platform is designed to reduce repeated infrastructure work while preserving explicit domain boundaries, traceable security controls and long-term maintainability.

## Target applications

- Administrative and operational systems
- Governance, risk and compliance platforms
- Workflow and approval applications
- Document and records management
- Multi-tenant business applications
- Internal enterprise tools

## Product goals

- Provide secure defaults without hiding important behavior.
- Support rich domain models and explicit application operations.
- Offer a reusable design system with explicit light and dark themes.
- Provide internationalization from the first implementation phase.
- Deliver an advanced open-source grid with server-side query processing.
- Include audit, privacy, observability and governance capabilities.
- Remain friendly to human developers and coding agents.

## Non-goals

- Replacing Rails conventions with a custom framework.
- Building a client-side SPA by default.
- Claiming automatic legal or security certification compliance.
- Introducing distributed services before operational need exists.
